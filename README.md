**WHO GLASS AMR Surveillance Analysis
Project Overview**
This project presents an end-to-end Antimicrobial Resistance (AMR) surveillance data analysis workflow using Python, based on publicly available data from the World Health Organization Global Antimicrobial Resistance and Use Surveillance System (WHO GLASS).
The analysis demonstrates how routinely collected AMR surveillance data can be processed from raw data through data quality assessment, cleaning, validation, descriptive analysis, epidemiological analysis, statistical testing, visualization, and results export.
The workflow is designed to demonstrate practical skills in Python, Pandas, NumPy, Matplotlib, SciPy, and Statsmodels, while applying epidemiological principles to AMR surveillance data.

**Project Objectives**
The objectives of this project are to:
1.	Import and inspect WHO GLASS AMR surveillance data.
2.	Assess data quality and completeness.
3.	Clean and standardize surveillance variables.
4.	Validate numerical and categorical data.
5.	Describe AMR patterns by country, antibiotic, pathogen, WHO region, and year.
6.	Estimate resistance using appropriate surveillance measures.
7.	Examine resistance patterns across pathogen–antibiotic combinations.
8.	Calculate 95% confidence intervals for resistance estimates.
9.	Assess associations between categorical AMR variables using appropriate statistical tests.
10.	Produce publication-quality visualizations.
11.	Export analytical results for reproducibility.
12.	Interpret findings while clearly documenting limitations.

**Data Source**
The project uses publicly accessible WHO GLASS AMR surveillance data.
Data source: World Health Organization — Global Antimicrobial Resistance and Use Surveillance System (GLASS).
The dataset contains surveillance information related to antimicrobial resistance, including variables describing geographical location, pathogens, antibiotics, years, and resistance measurements.
